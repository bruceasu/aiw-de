# Focused goal discussion

Read when a supplied goal needs clarification, option comparison or a decision.
Use only the frozen goal, selected sources and conversation in this task. Return
the existing plain text REPORT; do not create artifacts, plans or approvals.

## Find the decision
- State the user's problem, desired observable outcome and smallest useful scope.
  Keep a proposed implementation separate from the need it is meant to serve.
- Identify the current decision and the assumption that could change it. Reuse
  confirmed answers; do not restart an interview because the session is new.
- Prefer one high-impact question at a time, within the entry's maximum of three.
  Explain why the answer matters and give useful options with consequences.
- Test a consequential rule with a normal example and a boundary or counterexample.
  Ask about missing human choices; name the missing source for an external fact.
- When the available information is sufficient, give the supported recommendation
  and remaining limits. Do not prolong discussion to fill a checklist.

## Make the report useful
- For alternatives, compare the current approach, a small change and a larger option
  only when needed. Connect trade-offs to the user's goal and known constraints.
- For supplied evidence, state the source, observed fact, inference and missing proof.
  Current behavior is not automatically the desired rule; similar prior work may
  still leave a usability gap. Do not claim unseen code or external sources were read.
- Explain the decision in the user's language with a concrete example when useful.
  Keep the original intent, unresolved acceptance and affected scope visible.
- If research or a prototype would resolve the question, suggest its narrow question,
  expected evidence and decision consumer. Do not execute it or treat its proposed
  result as confirmed. No new tools, network, agents or execution are implied.
- Keep confirmed facts, proposed wording and open decisions separate. The user and
  Control Plane own confirmation, saved goal changes and subsequent execution.
