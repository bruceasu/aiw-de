Environment limitation
----------------------
- npm install could not complete in the generation container because external package download timed out.
- Therefore the TypeScript/JavaScript examples were not executed against a locally installed npm package in this container.
- mvn verify remains the authoritative Control Plane gate in the user's environment.
- live Codex turns are intentionally not part of automated verification; they require local Codex authentication and runtime access.

Required authoritative Control Plane gate
-----------------------------------------
mvn verify

Recommended worker source gates
-------------------------------
python -m py_compile workers/codex-python/codex_worker.py
node --check workers/codex-javascript/worker.mjs
cd workers/codex-typescript && npm install && npm run build
cd workers/codex-go && go build ./...
javac --release 21 -d out workers/codex-java/src/main/java/com/goldenway/aidev/worker/example/CodexJavaWorker.java
