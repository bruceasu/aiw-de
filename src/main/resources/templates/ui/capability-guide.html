Roles and automatic preparation

When automatic Workers are enabled, AgentFactory reuses compatible online Workers and prepares missing supported roles for confirmed execution tasks. External Workers can also register and participate.

CapabilityUse for
requirement-analysisClarify requirements and acceptance criteria
solution-architectureDesign solution boundaries and interfaces
implementation-planningPlan repository work and verification
codingImplement changes in the selected workspace
workflow-reviewIndependently review each step before advancing

Each native plan step is followed by an independent stage review. The next step starts after PASS. Saving a draft does not create execution tasks.

Technical capabilities and workspace access

Require a technical capability only when the task cannot proceed without it. Labels such as java, python or node are Worker declarations; they do not install tools or grant file and command access.

For native coding Workers, leave empty to pin the current Git HEAD automatically. Set a full commit to use that exact baseline.

A local result commit, independent review and delivery to the original branch are separate stages. This workflow does not push to a remote repository.
