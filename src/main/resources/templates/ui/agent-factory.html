1. 执行与登录

无法恢复密钥时，可以删除自己的旧模型登录并重新登录。Plan、任务和工作文件保留，旧任务的账户绑定不会自动更换。远端授权需另行在 ChatGPT 中处理。

高级部署：手工配置加密密钥

登录前需要配置 AIW_MODEL_CREDENTIAL_KEY，用于加密保存凭据。它不是 OpenAI API Key。若已保存过连接，请恢复原密钥，不要生成新密钥。

仅首次全新安装：在用于启动 Plane 的 PowerShell 会话中执行以下命令，再从同一会话启动 Plane。命令不会输出密钥。

if ($env:AIW_MODEL_CREDENTIAL_KEY) { throw '当前会话已有密钥，请核对原配置，不要覆盖。' }
$modelCredentialBytes = New-Object byte[] 32
$modelCredentialRandom = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$modelCredentialRandom.GetBytes($modelCredentialBytes)
$modelCredentialRandom.Dispose()
$env:AIW_MODEL_CREDENTIAL_KEY = [Convert]::ToBase64String($modelCredentialBytes)

以上只设置当前会话。请将同一密钥保存到工作区和数据库之外的受保护配置，并单独备份；每次启动须使用相同密钥。重启 Plane 后刷新本页，再填写连接名称并登录。

选择 Codex auth.json，导入为新的连接。不会扫描本机目录，也不会替换已有连接。

DeepSeek 使用 https://api.deepseek.com，密钥来自执行设备的 DEEPSEEK_API_KEY。修改环境后需重启 Plane 或对应外部 Worker。两种协议均有思考模式适配；Chat Completions 在完整回合结束后提交 SDK，保留原始推理与工具消息。标准端点不启用 Beta strict，本机始终校验工具参数。不会自动切换协议或借用 OpenAI 凭据。
