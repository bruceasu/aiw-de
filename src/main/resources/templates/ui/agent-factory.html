本机运行环境（高级）

本机 Worker 使用已安装的 Python。Codex 默认复用已有登录，由受控主机工具执行文件操作；只有需要独立账号环境时才指定目录。OpenAI API 使用平台进程已有的 API 凭证。工厂不复制凭证或自动安装依赖。

这里只设置默认模型和启动方式。计划、文件、命令及预算权限仍由原授权决定。

模型登录与凭证

由本机 Control Plane 统一保管凭证和刷新。Worker 按任务领取短期访问令牌。ChatGPT Responses 连接使用 OpenAI 运行时；导入的 Codex 连接使用 Codex App Server。

显式导入已有凭证

选择 Codex auth.json 或独立 ChatGPT OAuth 凭据文件。仅在你提交后导入，不会扫描用户目录。过期、来源不匹配或无法验签的凭据会被拒绝。Codex 凭据不会转为公开 Responses 凭据。

登录、导入或选择连接后，还需保存上方工厂设置。断开会立即停止本连接的新请求，并尝试远端撤销；未确认的远端状态会明确提示。
