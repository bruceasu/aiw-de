执行方式与登录方式分开设置。Codex App Server 通过本机 Codex 调用模型；Python Worker 直接调用 OpenAI Responses。登录或导入凭证后，在“登录与凭证来源”中选择匹配的连接。

本机运行环境（高级）

选择 Worker 本机凭证时，Codex 使用该 Worker 已有的登录；Python Worker 从运行环境读取 OPENAI_API_KEY，并通过 OpenAI Agents SDK 执行。选择 Plane 管理的连接时，长期凭证由 Plane 保管，Worker 按任务领取短期访问令牌。工厂不会自动安装依赖。

这里只设置默认模型和启动方式。计划、文件、命令及预算权限仍由原授权决定。

模型登录与凭证

这里管理由本机 Control Plane 保管和刷新的连接。登录或导入后，在上方“登录与凭证来源”中选择连接，再保存工厂设置。

  • ChatGPT OAuth 连接：通过 Continue with ChatGPT 登录，搭配“Python Worker（直接调用 OpenAI Responses）”。执行循环和工具调用由 Python Worker 管理，无需 Codex 程序或 API Key。
  • Codex 登录凭证连接：显式导入已有 Codex 凭证，搭配“Codex App Server（通过本机 Codex）”。仍需 Worker 本机安装支持外部凭证的 Codex。

显式导入已有凭证

选择 Codex auth.json 或独立 ChatGPT OAuth 凭据文件。仅在你提交后导入，不会扫描用户目录。过期、来源不匹配或无法验签的凭据会被拒绝。Codex 凭据不会转为公开 Responses 凭据。

登录、导入或选择连接后，还需保存上方工厂设置。断开会立即停止本连接的新请求，并尝试远端撤销；未确认的远端状态会明确提示。
