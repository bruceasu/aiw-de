这些记录可以说明什么？
  • 没有记录不代表没有执行。此页仅覆盖已有账本的最近尝试，不提供全局汇总。
  • 未知标记与已存耗时、费用并列展示；人工校正后也可能保留历史未知标记。
  • 同结果再次读取仅统计相同尝试中，已成功且资源与结果摘要相同的 READ 记录，不代表浪费，也不包括所有读取。
  • 启动开销、协调比例与真实质量分数尚未采集，不能从上报结论推算。
  • 展开记录可查看固定配置与正式交付的来源引用。每次交付最多列出 16 项，完整事实以原交付记录为准。
