Recovery semantics
Automatic lease recovery requeues tasks after lease expiry. EXPIRED also covers operator pause/cancel; a missing termination reason does not identify which path ran.
Manual recover follows an explicit Run failure and is recorded as RECOVERED with its own time and actor. It requeues failed tasks.
Attempt state, failure category and termination reason above are saved evidence. A Run event does not record an attempt or Worker association; these are not inferred. Later attempts show subsequent execution, not an invented recovery time.
