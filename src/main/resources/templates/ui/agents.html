创建一次性配对邀请

本机档案只接受回环连接和一次性邀请。远程档案要求 HTTPS、Control Plane TLS 服务端证书和 Agent 客户端 mTLS 证书；证书由部署的 CA 签发，Control Plane 固定配对时的客户端证书指纹。Agent 配对后先进入待批准状态；随后可在此页一次确认注册、精确 Grant 和当前进程启用。

远程部署需启用 agent-mtls Spring 配置并装载服务端 PKCS#12 密钥库与仅信任 Agent CA 的 truststore。Agent 主动连接；Control Plane 不保存 Agent 地址。
