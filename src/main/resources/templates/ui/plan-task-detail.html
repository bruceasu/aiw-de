What to do after failure

View failure diagnosis

This task failed. Fix the cause, then retry this task to continue the plan.
  1. Check the latest attempt below for its Worker, failure category and error code.
  2. Inspect that Worker's logs and attempt evidence. Fix the failed command, tool, permissions or runtime configuration before trying again.
  3. With automatic Workers enabled, AgentFactory prepares supported roles. Check factory status if preparation is blocked.
  4. After fixing the cause, enter a reason and retry the failed task below. Earlier accepted outputs and dependencies remain unchanged.

Retrying keeps the same plan and task IDs and adds a new execution attempt. Check local changes left by the failed attempt before confirming. No earlier step is restarted.

Where to find diagnostics

Diagnostic JSON includes attempt IDs, Worker identity, failure codes, explanations and recovery guidance. An authenticated assistant can use this API to investigate.

Attempt evidence is stored outside the working directory, under AIW_WORKER_EVIDENCE_ROOT or the default .aidev-attempt-evidence directory. Match owner.json by Attempt ID. Historical records may not include command output.

New Codex failures log the tool type, call ID, exit code, diagnostic code and evidence directory. Only known error patterns are classified; unrecognized failures remain UNRESOLVED_TOOL_FAILURE. Raw command output is not retained.
