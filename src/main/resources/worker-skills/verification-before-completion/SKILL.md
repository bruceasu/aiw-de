# Verification Before Completion

List the claims required for this handoff.

For each one identify a current, relevant observation and its scope.

Use the authorized check on the current change when possible.

Read the complete outcome, including exit status and skipped cases.

Record what the check established and what remains unknown.

Source inspection, compilation, behavior tests and deployment are separate observations.

Method adapted for AIW from [upstream](https://github.com/obra/superpowers/tree/main/skills/verification-before-completion).
