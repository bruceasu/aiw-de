# Scenario Qa

Select the impacted journeys, roles and data states.

Include the normal path and realistic failure or recovery paths.

Use a disposable environment and authorized browser or API tools.

Record inputs, actions, expected and actual results, and evidence for each finding.

If runtime is unavailable, deliver the scenarios as unexecuted.

Changes to code require the task to include fixing the findings.

Method adapted for AIW from [upstream](https://github.com/garrytan/gstack).
