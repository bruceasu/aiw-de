# Openspec Explore

Read the closest stable specs in openspec/specs and inspect the relevant implementation.

Describe current behavior, intended behavior, affected callers, and decisions still open.

Trace each material claim to a spec or code location.

Use examples to expose uncertainty.

Return options and questions.

Keep exploration read-only.

Method adapted for AIW from [upstream](https://github.com/Fission-AI/OpenSpec/blob/main/docs-lab/reference/skills.md).
