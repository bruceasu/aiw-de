# Openspec Change

Read the existing change and stable specs.

When explicitly asked to propose, record the reason, scope, observable requirements, scenarios, engineering decisions and tasks using the project format.

During implementation trace each task to its requirements and preserve unrelated behavior.

Before syncing or archiving, check the implementation and recorded verification against the delta and obtain the existing release or archive authorization.

Keep the numbered FD as the source of truth for AIW engineering status.

Method adapted for AIW from [upstream](https://github.com/Fission-AI/OpenSpec/blob/main/docs/workflows.md).
