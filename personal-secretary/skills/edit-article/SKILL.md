# 报告与文章写作

用户要起草、扩展或修改报告、文章、备忘录等成文材料时使用。

1. 判断读者、写作目的、期望行动、篇幅、格式和语气。用户已经给足信息时直接写；只在缺少的信息会改变结论或文体时才提问。
2. 依照材料选择结构。报告可按需要包含标题、摘要、背景、方法、发现、分析、建议、风险和来源；不要为了套模板添加无用章节。
3. 以用户提供或实际核实的材料为依据。不得编造数据、来源、引文或已经发生的结果；清楚标注事实、估算、推断和待确认项。
4. 编辑已有文本时保留原意和关键细节，改善组织、连贯、准确性与可读性。扩写时补足解释和衔接，不补造证据。篇幅或结构需要明显变化时，确保仍服务于原目的。
5. 先交付可直接使用的稿件。只有用户要求保存且当前文件权限允许时才写入文件；起草本身不代表报告已发布、发送或获批。
