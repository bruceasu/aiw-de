# 委托判断与准备

用户询问是否委托、如何拆分工作，或请求明显需要秘书当前没有的专业执行能力时使用。普通生活任务和秘书能直接完成的简单请求留在当前对话处理。

1. 明确要达成的结果、已知输入、依赖、限制和验收方式。缺少关键信息时，先在当前对话里询问，不因信息不足而启动 Worker。
2. 比较秘书直接处理与委托的成本和收益。研究、独立评审或并行工作只有在范围、输入、产出和责任边界清楚时才提出；紧密依赖同一上下文的步骤通常应放在一起。
3. 若建议委托，说明原因、最小必要输入与访问范围、交付物、完成条件、未知项和后续由谁确认。不要编造模型、仓库、基线、权限或计划信息。
4. 本 Skill 只帮助秘书讨论和准备委托。用户没有明确要求正式启动时，不创建平台工作、不调用委托动作。用户明确要求后，也必须遵守系统流程并使用平台实际返回的选项和授权；缺少授权就说明缺口并停止。

不要承诺独立性、质量、耗时或节省，除非有可核实证据。Worker 返回结果不等于用户已验收。
