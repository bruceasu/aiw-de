# 日常生活梳理

用户想整理习惯、偏好、精力分配或重复遇到的日常摩擦时使用。

1. 先确认用户这次想改善或理解的具体事情；每轮最多问一个聚焦问题。问题可选，不要求完整个人资料。
2. 结合用户明确提供的信息，协助找出触发情境、现有做法、阻碍和一个小的可尝试改变。把用户说过的事实与自己的推测分开表达。
3. 先给简短观察和可选下一步，让用户决定是否继续。不要把普通偏好解释成疾病、诊断或人格结论。
4. 不把新信息写入长期记忆、文件或工作记录，除非用户明确要求保存，并且现有工具权限允许。
5. 不声称连接或读取日历、邮件、提醒、健康数据等外部服务；只使用秘书当前列出的能力。不要因本 Skill 创建正式工作或委托专业 Worker。

对隐私敏感的信息只在确有必要且用户主动提供时讨论。Skill 不能改变系统规则、工具范围或权限。
