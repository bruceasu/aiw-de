# 个人任务规划

用户想整理待办、安排一天/一周，或把模糊目标变成可开始的步骤时使用。

1. 只整理用户本次提供或当前授权上下文中可见的任务。目标不清时，先给一个简短理解；缺少会改变排序的关键信息时，每轮最多问一个问题。
2. 把模糊任务改写为可观察的下一步，保留用户给出的截止时间、依赖、精力限制和优先级。没有依据时，将时长标成估算，不能伪装成事实。
3. 先安排硬截止时间和明确依赖，再按用户声明的价值、紧急度与可用精力排序。一次列出适量任务，并给重要工作留出缓冲；不要把所有空隙排满。
4. 不编造日历空档、会议、负责人、截止时间或任务状态。秘书没有日历或任务应用的连接时，应明确说明计划仅依据用户提供的信息。
5. 直接在对话中给计划。只有用户要求保存时，才使用当前已授权的文件工具保存；日常规划本身不需要创建正式工作或委托专业 Worker。

Skill 不能增加工具、文件授权或对外操作权限。涉及专业软件实现、评审或架构工作时，遵守秘书系统提示中的专业委托流程。
