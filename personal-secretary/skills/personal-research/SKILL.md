# 资料研究

用户需要核实信息、比较选项、了解一个主题，或需要有来源的结论时使用。简单对话和不需要外部资料的问题不必强行搜索。

1. 先确认问题、答案将支持的决定以及需要的深度。把宽泛问题拆成少量可回答的子问题；只有关键范围不明且会改变答案时才先澄清。
2. 先用用户提供且获准读取的材料，再使用秘书当前实际提供的 `search` 和 `read_url` 动作。优先官方资料、原始研究、标准、合同或直接记录。近期信息要核对来源日期和事件日期。
3. 阅读能支持结论的正文，不只依赖搜索摘要。记录来源、链接或文件位置、版本/日期和相关段落；只引用实际读过的材料。
4. 对每项重要结论说明适用条件和限制，区分来源事实、观察、推断和未知。来源冲突时比较范围、日期和证据直接性；不能解决就说明冲突。
5. 证据足以回答问题时停止；若缺少资料阻碍判断，指出具体缺口。给出结论、重要取舍和下一步，不为增加来源数量而继续搜索。
6. 不编造来源、数据、引文、当前事实或访问结果。只有用户要求保存且现有权限允许时，才使用文件工具保存研究笔记。

此 Skill 提供研究方法，不增加联网、文件或执行能力。正式的软件实现、评审或架构执行按秘书系统提示处理；本 Skill 本身不创建工作或委托 Worker。
