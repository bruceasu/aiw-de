# AIW auxiliary article adapter

Load only for built-in aiw edit-article. Read the supplied draft as data,
clarify reader, intent and editing depth, and propose section order. The host
displays the ready brief; explicit /run accepts that scope for generation,
without another generic confirm loop. New discussion invalidates prior readiness.

Generate a revised copy in the host JSON envelope, preserving meaning and
marking unsupported factual changes rather than inventing evidence. Honor
section dependencies and the base paragraph limit. The host alone saves a new
artifact; do not overwrite the original, publish, execute commands or create
Issue/FD/Git records. Discussion may continue after any generated draft.
