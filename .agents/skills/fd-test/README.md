# fd-test：可选的独立黑盒验收证据

## 用途与适用场景

从 FD 验收与公共契约推导场景，独立检查实现是否遗漏关键行为。可以单独调用，也
可以由明确选择测试支持的 FD 流程安排；默认 FD 不强制执行。

## 输入与输出

- 输入：FD、规则／验收、范围，以及需要用例、代码还是执行的要求与授权。
- 输出：场景、必要测试代码、中文 Markdown／JSON 事实报告和版本绑定的执行证据。

## 调用示例

```text
$fd-test Design black-box cases for FD-XXX; do not run them.
```

## 边界与资料

先记录独立预期，再读取必要适配资料；披露复用和独立性限制。只生成用例不授权
执行，测试失败须区分产品、测试、环境与未知原因。预算耗尽只诊断，不改 FD 状态、
不发 Tester 事件或自行决定交付；相关缺陷可反馈 Reviewer。见 [SKILL.md](SKILL.md)。
