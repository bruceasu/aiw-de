# grilling：沿决策依赖追问

## 用途与适用场景

用户希望深入检验一个计划、设计或想法时使用。把决策组织为依赖树，先讨论前置条件
已明确的问题，收到实际答案后再推进后续分支。

## 输入与输出

- 输入：计划／设计、约束、已有事实和用户偏好。
- 输出：分轮问题与建议、用户确认的决定，以及尚未解决的依赖。

## 调用示例

```text
$grilling Stress-test this design and its assumptions.
```

## 边界与资料

Agent 不代替用户回答取舍问题。事实调查和子 Agent 操作仍遵守宿主预算与授权；
与 Issue 结合时遵守其当前提问范围，不另开一套批准流程。达成理解不等于获准实施。
具体轮次和结束条件见 [SKILL.md](SKILL.md)。
