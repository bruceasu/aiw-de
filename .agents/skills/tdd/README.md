# tdd：通过测试先行实现行为

## 用途与适用场景

实现期间对规则明确、结果可确定的行为进行小步 Red／Green 循环。适合核心计算、
状态规则和缺陷回归；不是在实现结束后补测的别名，也不是所有工作都要采用。

## 输入与输出

- 输入：已确认规则、具体例子、行为边界、实现范围与执行授权。
- 输出：实现和回归测试，以及实际 Red／Green、版本、命令和限制的记录。

## 调用示例

```text
$tdd Implement this confirmed rule one behavior at a time.
```

## 边界与资料

导入、配置和环境错误不能冒充有效 Red；预期结果不能来自同一生产逻辑。未实际
执行不能声称完成 TDD。测试支持不绕过仓库语言限制或失败预算，耗尽后只诊断。
见 [SKILL.md](SKILL.md)、[断言例子](tests.md) 和 [替身边界](mocking.md)。
