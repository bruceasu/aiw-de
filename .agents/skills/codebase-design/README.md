# codebase-design：模块与接口设计语言

## 用途与适用场景

讨论模块接口、职责边界和可测试性时使用。核心是用小而稳定的接口封装足够完整的
行为，减少调用方负担和跨模块修改，而不是为了增加抽象层而设计。

是独立设计方法，可供FD设计、局部实现设计及评审参考，不是code-review的子流程。

## 输入与输出

- 输入：模块职责、调用方式、变化压力和设计问题。
- 输出：接口／边界建议、取舍、可替换依赖与测试面的分析。

## 调用示例

```text
$codebase-design Review the boundary and interface of this module.
```

## 边界与资料

产出设计指导，不自动实现、提交或运行验证。默认本会话比较方案；明确授权独立
分析时才使用最多两次有界静态Agent，不递归派发或借换方法重置预算。

尊重项目现有术语；接口深度、adapter数量和测试面是判断依据，不是绝对规则。
保留必要的内部／集成／契约／端到端验证，不自动删除既有测试。未解决的业务规则
明确标注；FD内设计回到当前FD，不增加固定阶段。
概念定义与可选方法见 [SKILL.md](SKILL.md)。
