# fd-release-gate：评估真实发布准备

## 用途与适用场景

实现已完成、确实计划发布时，评估证据是否足够。适用于各领域，可评估一个或多个
FD，也可评估其它已实现变更，不要求先创建FD。

## 输入与输出

- 输入：已实现变更、发布范围，以及适用的迁移、数据、权限、审计、回滚、监控和责任人证据。
- 输出：Release Review、开放风险、下一步，以及 `GO`／`GO_WITH_RISK`／`NO_GO`。

证据需要指向候选版本和目标环境，并区分已观察、计划、未执行、未知与不适用。
关键证据缺失给出 INCOMPLETE／NO_GO；GO_WITH_RISK 只用于已有明确责任人与
授权决策者接受证据的非关键剩余风险，模型不能代为接受风险。

## 调用示例

```text
$fd-release-gate Assess release readiness from this evidence.
```

## 边界与资料

只读评估，不编造缺失程序或责任人。不是 Issue 讨论方法，也不是每个 FD 本地
合并／归档的门槛；GO 不授权部署。不修改迁移、回滚或监控文件来补证据。
见 [SKILL.md](SKILL.md)。

本入口由旧 finance-release-gate 改名，仓库不保留旧别名。发行目录和全局安装
不会自动迁移；后续同步时需检查并移除旧副本。默认在对话返回评估，不运行测试、
联网、发布或部署。
