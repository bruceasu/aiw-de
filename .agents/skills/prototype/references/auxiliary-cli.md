# AIW auxiliary prototype adapter

Load only for built-in aiw prototype. Use the selected logic or UI method to
clarify the question, then generate from the host's ready brief on explicit
/run. Branch selection is fixed at creation; do not silently switch it.

Return throwaway source/content in the host JSON envelope, with visible state,
usage notes and no external services. The host writes separate result artifacts,
never mounts a route, modifies production files, runs a server or saves a Git
branch. Do not claim runtime verification. User feedback can guide another
discussion and generation. An accepted design needs a separate implementation
request; prototype creation is not an Issue/FD event or production delivery.
