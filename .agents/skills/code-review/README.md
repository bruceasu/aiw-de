# code-review：独立审查分支、PR 或 diff

## 用途与适用场景

适合单独检查指定提交以来的变更，包括没有编号 FD 的工作。先固定比较基线与实际
被审查版本，再分别检查仓库标准和原始需求。

## 输入与输出

- 输入：分支／PR／提交基线、变更范围、需求依据和仓库标准。
- 输出：按 Standards／Spec 组织的发现、位置、影响、建议和证据限制。

## 调用示例

```text
$code-review Review the changes since develop.
```

## 边界与资料

显式调用允许最多两个有界独立静态审查 Agent，不自动修复或循环评审。
不替代 fd-review 的正式通过事件，不批准交付或发布；普通 FD 不重复启动这两套
完整流程。未提交内容必须在请求范围内明确计入。见 [SKILL.md](SKILL.md)。
