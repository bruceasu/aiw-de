# diagnosing-bugs：基于证据诊断故障

## 用途与适用场景

适合难以定位的错误、间歇故障、性能回归或原因不明的测试失败。默认从已有输出
与代码进行静态分析，不要求先运行失败命令；运行复现按已有具体授权和预算选择。

## 输入与输出

- 输入：症状、复现步骤、版本、日志／已有捕获，以及可访问范围。
- 输出：观察结果、产品／测试预期／夹具／环境原因分类、已确认根因或有依据的
  假设、候选修正、证据限制、剩余预算和下一步；不冒充已复现或已修复。

## 调用示例

```text
$diagnosing-bugs Diagnose this failure from the supplied logs.
```

## 边界与资料

诊断与实施分开。运行时复现、测试、临时插桩和环境操作需要各自授权；未授权时
明确记为未运行，不能把静态推断写成复现成功。FD出现异常可按需使用，结果回到
当前FD／报告；不产生新的必经阶段或自动重构。

测试进入diagnosis-only后，仅使用已有材料做一次有界静态分析，已有分析则引用；
不实施候选修正、不再运行或通过其它Skill重置预算，保留现场。报告完成不等于
缺陷修复，未解决验收问题仍阻断交付。见 [SKILL.md](SKILL.md)。
