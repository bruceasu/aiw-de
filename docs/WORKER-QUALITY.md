# Worker 质量对照

运行 `python scripts/worker-quality.py` 可复查三类平台行为。使用本机 Python、JDK 和 Maven 离线依赖。需要指定 Maven 缓存或离线设置时，加 `--maven-repository` 和 `--maven-settings`。脚本只运行表中的固定用例，输出 JSON。`localCheckMs` 包含本机测试进程开销。模型调用、Token、费用和领取等待留空。

| 场景 | 固定输入 | 判定 |
|---|---|---|
| 文字开工 | 持有共享目录锁的 Git 样例、已有报告、一个通用文字任务 | 可开始准备，读取前序报告，交接继续指向原项目。 |
| 文件交付 | 临时文件需要两处修改，任务要求执行两项检查 | 修改一次落盘。检查前的旧回执、非零退出和后续改动都无法充抵必需检查。 |
| 中断重试 | 一个过期的实际运行记录和明确的停止确认 | 原尝试仍可查看，人工重试只重新开放当前任务的领取机会。 |

## 实际任务对照

每一组使用相同任务、相同源文件版本、模型和推理强度、工具规则及必需检查。改动一项后再跑另一组。文字用例可使用一段固定资料，核对答案中的三个事实及其引用。文件用例使用同一新闻样例，核对默认日文、显式简体中文与 JSON 结构。中断用例应使用隔离的执行，确认 Worker 停止后手动重试。

每组记录任务和尝试编号、是否满足验收、是否返工、领取等待、第一次模型调用前准备、模型调用数、已知 Token、估算费用及缺失记录。把平台准备或恢复失败、模型未按要求执行和交付检查失败分开写。验收以产物及正式回执为准。真实模型结果不用于替代平台定向用例。
