# FD-129: 秘书完整交互日志导出

**Status:** In Progress
**Revision:** 1
**Review policy:** Independent
**Priority:** Medium
**Evidence policy:** Dual

## Problem

用户需要把秘书的一次会话及相关执行过程保存到本机。当前页面能查看部分交互，但记录视图有限，且不是每次模型请求的完整原文。

## Options and decision

复用本机 SQLite 中已有的会话、运行、模型历史、工具回执和事件，提供一个按会话导出的 JSON。不要重建未保存的 HTTP 请求，不扩展采集和保留策略，也不增加额外导出格式。

## Solution

在秘书本地 API 增加按 `workId` 导出单个会话的只读操作。分页读取该会话全部已保存消息，关联其秘书运行及对应模型历史、已保存的 OAuth 模型响应、工具回执和执行事件；构建明确的 JSON 投影，不直接序列化运行配置或凭据绑定。递归排除模型推理记录和凭据字段。对源数据已有的截断标记和缺失情况保留说明。

秘书会话界面增加“导出交互记录”按钮。用户主动点击后，请求本机 API 并通过秘书主机上的浏览器下载一个 JSON 文件；操作前说明文件可能含私人会话内容，且会话正文中的敏感文字会按原文保留。API 沿用现有 session 与 CSRF 保护，并限制为本机请求，不访问 Plane 或网络。

## Scope

- 导出一个所选秘书会话及与其关联的本地秘书运行。
- 保留已保存消息、SDK 交互历史、已保存的 OAuth 响应、工具调用／回执及事件／用量／错误，并提供顺序和会话／运行关联；不声称包含未保存的 API Key 响应或完整 HTTP 原文。
- 导出全部当前保留的记录，不受交互查看器的预览条数和字符数限制；保留记录自身已有的截断或占位信息。
- 不输出凭据、访问令牌、认证头、配置中的模型连接绑定或模型内部推理。
- 只在本机浏览器下载；不上传、重放、补造或改变原记录。
- 仅改 `personal-secretary` 本地服务和 UI，以及对应文档；不改 Plane、Worker 执行服务或数据库结构。

## Acceptance

- 用户从指定会话发起一次导出，得到一个仅包含该会话和关联本地秘书运行的 JSON 文件。
- 消息、模型交互、工具调用／结果和运行事件按时间顺序组织，并保留对应运行和消息标识。
- 导出使用底层当前保留的数据，不复用查看器的预览截断；源记录标明缺失、截断或占位信息时，在 JSON 中如实保留或说明，不声称含有未保存的原文。
- 不导出结构化模型连接凭据字段、令牌、认证头、凭据绑定或模型推理记录；会话正文中的敏感文字按原文保留并由界面提示。
- 导出前提醒文件可能包含私人资料；只允许秘书主机的本机浏览器下载，不发送到远端。
- 导出不修改会话记录，不启动模型、工具或委派，也不新增存储、采集、保留策略、依赖或迁移。
