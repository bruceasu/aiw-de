# FD-138: 缩短文字任务的开工路径

**Status:** Complete
**Revision:** 5
**Review policy:** Independent
**Priority:** Medium
**Evidence policy:** Markdown

## Problem

普通文字任务也会等待项目目录锁、探测 Git、加载项目指令并扫描目录。共享目录正在执行文件任务时，单纯生成文字也可能长时间无法开工。

## Options and decision

复用 Worker 现有独立目录及正式交接。开工路径按实际任务能力选择，保留原权限与执行模型。

## Solution

无 Broker、无恢复检查点的 Python OpenAI 通用文字任务，在 Plan 下使用本次尝试的独立目录，保持只读核对和该目录的锁，跳过 Plan 共享锁、Git 探测、工作树和项目目录扫描。按原规则核对正式输入报告和知识资料。文字交接保留最近同 Plan 可用的项目位置，供下游文件步骤使用。

## Scope

文件任务、审批/检查点续接、其他运行时继续采用原工作位置。页面的当前工作在确有对应事件时给出领取、首轮准备和模型调用耗时。没有对应记录时显示未记录。

## Work items

- [x] 1.1 为无文件权限的文字任务提供短路径，保持交接与原恢复语义。
- [x] 1.2 在已有尝试和模型事件上提供可核对的时段，编译及定向验证。

## Acceptance

- 项目主目录有锁或 Git 时，普通文字任务在独立目录继续。交接报告可读取，下游文件任务仍获得正确项目位置。
- 文件任务和检查点续接继续使用原有锁与输入校验。
- 页面耗时来自真实记录，时间缺失或顺序异常时保留未知。

## Verification

涉及工作区并发与交接，需独立审查。Worker 编译、JDK 25 离线 Maven `compile` 和 `python -m unittest test_plan_workspace_lock` 的 5 条定向用例通过。覆盖共享锁保持占用时文字任务可独立开工、无需探测 Git、读到前序报告并传递其项目位置。首轮模型准备和请求用时使用同一 Worker 事件时钟，首次领取前等待使用 Plane 时钟。未跑真实 Plane、模型或浏览器，暂无实际耗时对照。

审查后将问答检查点实际目录和下游项目目录分别保存，续接复用已验证的私有目录。页面排除本地预检拒绝事件，首轮请求时长取匹配终止事件的实际 `durationMs`。Worker 编译、JDK 25 离线编译和同组 6 条定向用例复跑通过，新增用例覆盖非空项目内文字问答续接。Worker 会话 `fd138-worker-ize6y4k2`，来源 `FD-138-000003-changes-requested`。
