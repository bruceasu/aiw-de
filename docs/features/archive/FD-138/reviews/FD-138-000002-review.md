1. **P1　新文字工作区会破坏正式问题的检查点。** 入口只排除已携带 `checkpointInputs` 的任务，首次运行的文字任务仍可开原生会话并提出正式问题。`native_run.py:187` 对实际 `workspace.cwd` 计算检查点摘要，`plan_workspace.py:311` 写入的 `workingDirectory` 却指向继承项目位置。续接在 `plan_workspace.py:130` 读取该位置，并在 137 行核对其内容摘要。项目目录含文件、文字目录为空时，正常答复将导致 `HANDOFF_CHECKPOINT_TREE_CHANGED`。检查点须引用实际被快照的目录，并保持续接的文字目录隔离。只改 Manifest 字段仍需检查原续接路径会否因角色根目录有 Git 而为原文字检查点新建项目工作树。
2. **P2　模型预算拦截会被显示为已发生的首次模型请求。** `openai_api_runtime.py:440` 在输入 Token 达预算时记录 `model-request`、`status=error` 并抛出异常。693 行还会发送错误结束记录。`ExecutionRuns.java:297` 和 313 至 316 行按事件类型和时间相减，因而可以给出准备耗时和请求耗时，实际此时未调用模型。应排除明确的预检拒绝，并在有实际模型终止耗时的证据时才显示请求耗时。错误终止缺少耗时证据时保留未知。
