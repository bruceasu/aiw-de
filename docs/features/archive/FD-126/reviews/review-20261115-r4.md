2. **启动前检查实际的 `ProcessSpawnParams`。** Windows 能力探测调用 `protocol_capability(process_spawn=True)`，从已安装 App Server 生成的 schema 中要求 `ProcessSpawnParams` 包含本次请求使用的 `command`、`processHandle`、`cwd`、`streamStdoutStderr`、`outputBytesCap`、`timeoutMs`、`env`。缺少定义或字段时抛出能力不支持错误，`guarded-command-v1` 不会被添加。Linux/WSL 继续探测 `CommandExecParams`。
