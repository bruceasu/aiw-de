- Factory 先用精确配置或语义匹配结果，再组合登记 Skill；需要补充方法说明时产生声明式候选供审阅，不执行生成代码或新增工具。配置和资产版本冲突被拒绝；集合顺序变化不导致已存版本被覆盖。任务事实保持在 WorkTask/TaskInput，知识仅接受用户选定、Owner/仓库范围内的内容版本。
- Intent+version 唯一、generation CAS；准备只作数据库/目录校验，不持事务调用模型、进程、Git 或网络。缺权限/预算/定价/引用/后端/Worker 时保留 BLOCKED 原因和恢复动作，未创建任务、不消耗 TASKS。PREPARING→READY、配置绑定、固定依据、业务任务及任务消耗同事务提交，READY 重放返回原任务。
- 基础 Worker 重新登记先失效旧能力元数据；新登记包含实际 Runtime、SDK/协议/适配器证据和资源政策摘要。claim 在 Lease/Attempt/预留事务内固定所选能力快照；新能力仅派给兼容 Python。新路径不受启动 role 固定，不扩展 Go/TS。
