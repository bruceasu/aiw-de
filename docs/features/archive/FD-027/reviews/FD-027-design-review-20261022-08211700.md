# FD-027 设计审查

<!-- aiw-data: FD-027-design-review-20261022-08211700.json -->

建议：**changes-needed**。后端和真实工具资源政策仍待用户选择；以下工程合同亦需在就绪前固定。

- **D027-01 / P1** — `运行后端与取消`、工作项 1.1/3.2/3.3：设计正确拒绝提示词授权和原生工具旁路，但所选后端的实际调用路径与信任边界仍未落定。最小修正：列出每个可广告适配器的“Agent 调用→029 准入/意图→可信执行→正式回执”路径；模型只可请求登记工具，不持有文件系统、任意进程、网络或平台凭证的其他入口。模型传输凭证留在可信端，不下放给可执行项目代码。文件/受控 Git 与命令执行分开说明，后者必须有经确定的资源隔离；无法隔离时不广告该能力并在准备阶段阻塞。Codex 原生工具若不能逐次受控，就保留旧合同用途，不能广告新授权合同。029 拥有授权及适配器机制，027 拥有实际 Runtime 接线与能力声明。
- **D027-02 / P1** — `配置准备与快照`、工作项 1.1/2.3/3.1：配置、准备与能力广告只有候选字段，尚不足以原子保证“准备好且兼容，才产生可领取任务”。最小修正：固定 PreparedConfigRef（ID/revision/digest/protocol/resultKind/Skill 与知识版本/工具需求）、WorkerCapabilities（协议、Runtime、适配器版本、平台、资源策略）、Preparation（intentId/version/generation/state/configRef/error）及封闭错误码。完成准备和创建任务采用唯一 intent/version 与事务/CAS；claim 固定能力版本，Worker 在执行前复验快照摘要，失配拒绝而非取最新配置。明确准备失败、无兼容 Worker、缺权限的重新准备入口和版本变更规则，并与 028 的 yield/继续输入一致。

人工 Gates：首期后端/部署组合、实际工具和资源政策保持未决；“Python”不足以替用户选择后端。软件职责表是候选配置，不是实际授权。

正向观察：配置优先复用、声明式生成不能注册工具、Go/TS 不兼容新版不派发、知识归属及预留分类不冒充能力均有覆盖。029 先在既有入口交付安全基础，027 再独立验收新配置消费，可消除整体交付依赖环。

证据范围：Revision 2 FD、批准 Issue 片段及 Python/运行协议本地静态搜索；未启动后端、Worker、模型、容器或命令，未执行测试、编译或网络。未证明某后端已满足新增安全合同。
