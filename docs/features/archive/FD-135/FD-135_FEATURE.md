# FD-135: 复杂任务的轻量工作清单

**Status:** Complete
**Revision:** 5
**Review policy:** Independent
**Priority:** Medium
**Evidence policy:** Markdown

## Problem

复杂任务经历多轮模型调用和工具执行，用户只能看到运行阶段。长历史被压缩后，Worker 也可能失去对已做事项和下一步的把握。

## Options and decision

借鉴 HelloAgents 的 TodoWrite 完整列表更新。首期随受控 Python OpenAI 文件任务提供可选工具，沿用运行事件和权限。Worker 在需要时更新一次当前清单，简单任务可以直接交付。把清单保留在当前尝试状态，可以在原有模型调用内补回上下文。

## Solution

清单最多五条，每条有简短名称和待做、进行中、已做状态，最多一个进行中。提交完整列表，允许清空，不重复记录相同列表。名称是面向用户的工作摘要，避免路径、命令参数、凭据及原始输出。限制和校验仅适用于专用事件，其他运行事件的元数据规则沿用现有设计。

现有任务详情展示最新尝试的清单。历史压缩后将当前清单以任务资料形式纳入已有请求。重试只带入同一任务、同 Owner 和同指令版本的原清单，受控续接也可读取已绑定直接前身的记录，标为待核对线索。旧记录不会成为新尝试的已做事项，清单状态不参与验收，权限和派发不随之变化。

## Scope

首期支持打开运行通道的受控 Python OpenAI 文件任务。新 Worker 在 Plane 明确声明支持时提供工具。继续使用现有事件保留期限及 Owner 访问控制。清单的已做标记是 Worker 描述，实际文件、命令结果仍从正式回执核对。

## Work items

- [x] 1.1 接通有界、可选的清单工具和既有运行事件。
- [x] 1.2 在任务详情显示本次清单，原尝试记录仅作为接续线索。
- [x] 1.3 静态校验归属、兼容、失败和数据安全边界，并完成离线编译。

## Acceptance

- 直接完成普通任务无需调用清单工具。关闭通道或 Plane 未声明支持时不提供工具。
- 最新清单可见，空清单会清除本次展示。无权限和其他任务访问不能取得清单。
- 多个进行中、过长或带控制字符的条目会被拒绝，之前记录保持有效。
- 历史压缩后下一次模型调用仍收到本次清单。合法重试拿到旧清单作为待核对资料，勾选不能替代 FD-133 检查。

## Verification

清单包含新增的 Owner 可见内容，涉及工作协议和重试资料归属，实施后独立审核。`node scripts/compile-worker-runtime.mjs` 和 JDK 25 离线 Maven `compile` 通过。`python -m unittest test_run_channel` 的 14 条离线用例通过，覆盖真实 SDK 本地工具调用、能力声明、去重、无效输入、清空及清单不会被当作工作区进展。已静态核对最新尝试、Owner 和续接范围。未运行实际 Plane、在线模型或浏览器。

初次独立审查发现真实本机证据写入会拒绝清单字段。修正后，清单直接进入受能力协商与控制边界保护的专用事件，普通本机证据规则保持原样。回归用例用会拒绝该字段的证据替身确认清单不会走普通证据写入。Worker 编译与同组 14 项定向用例复跑通过。Worker 会话 `fd135-worker-bpd0zxv8w`，来源 `FD-135-000003-changes-requested`。

[首次独立审查](reviews/FD-135-000002-review.md)指出原离线用例绕过了证据字段许可。[独立复审](reviews/FD-135-000004-review.md)核对修复与定向证据后通过。
