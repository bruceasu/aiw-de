# FD-026 设计审查

<!-- aiw-data: FD-026-design-review-20261022-08211700.json -->

建议：**changes-needed**。下列事项是候选设计已承认但仍需固定的工程合同，阻塞 design-ready；不是已实现算法的缺陷报告。

- **D026-01 / P1** — `候选流程与执行模型`、`并行、汇合与局部结束`、工作项 1.1/2.3/3.1：只有“显式激活范围元数据”，尚不能确定如何计算同一次汇合的必要成员、如何识别回跳，或何种 goto 合法。最小建议采用可校验的嵌套 region：固定 regionKey、父 region、节点集合、入口、汇合点和 loop header；条件分支在汇合前不任意交叠，拒绝不可结构化图。运行时用 planVersion+regionKey+activationId+iteration 标识本轮；选路事务固定所选子范围及必要成员，未选路径从未成为必要成员，失败/取消成员不得改成未选。依赖只引用当前范围本轮成员或明确导入的固定祖先结果。前向 goto 不得越过必要依赖；回跳只指向声明的 loop header，旧轮已启动工作收尾/确认取消后才能新建轮次；拒绝进入兄弟/子范围或跨越尚在途的并行范围。end 只关闭局部路径，不自动补齐必要成果。用少量合法/拒绝图与成员示例固定算法，再实现。
- **D026-02 / P1** — `回跳、控制及变更`、工作项 1.3/3.2/3.3/4.3：唯一转移 ID 还不足以定义 pause、claim、回答消费和取消的并发顺序。最小修正：固定控制 generation、计划版本及 execution 版本；在统一事务/CAS 门禁下检查当前控制状态、消费来源事件、生成后继及任务意图；跨模块通知使用持久化 outbox 或等价可重放边界。明确暂停与 claim 的线性化点及已领取在途工作的处理，恢复仅消费未应用事件。取消以精确 task/attempt/Lease 收确认；迟到完成保留事实但不得自动推进已终止/被替代执行。问题回答 APPLIED 回执应绑定唯一推进结果，不在两个模块分别宣布应用完成。

人工 Gate：FD-029 的预算计量和未配置政策保持未决；本报告未替用户选择。
