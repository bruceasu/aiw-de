## P2：默认数据库说明忽略当前激活的 SQLite profile

README 及中英 Quick Start 都说明未设 `AIW_DB_URL` 时默认连接 PostgreSQL。实际 `src/main/resources/application.yaml` 设置 `spring.profiles.default: sqlite`；默认加载的 `application-sqlite.yaml` 将 datasource URL 覆盖为 `jdbc:sqlite:d:/temp/data/aiwde.db`，同时指定 SQLite driver 和 database.mode。因此正常无显式 profile 的启动并不使用所述 PostgreSQL 默认，读者会错误判断未配置／恢复环境时的数据位置和连接目标。

最低修复：将三处默认说明对齐当前默认 SQLite profile 与其路径，继续推荐显式设置 `AIW_DB_URL`、创建目录；若需解释基文件 PostgreSQL 候选值，应明确默认 profile 覆盖关系。不要求修改运行配置或增加部署功能。
