## 决策

**退回本轮测试验收。** [独立测试报告 r19](FD-005-test-report-r19.md) 的唯一获批命令 exit 0，15 个实际执行用例全部通过，包含真实本地 Git 工作树锁定导致删除失败时不调用 `/complete` 的修复场景。原始输出和执行摘要保存在 `tests/fd005/evidence-r19/`。这些结果予以保留，不重写为失败。

本轮 33 个适用的 API Worker 行为场景只覆盖 15 个，需求场景覆盖率 **45.45%**；业务代码分支覆盖率**未测量**。目前没有低于 70% 或无法测量的覆盖率例外。18 个未覆盖场景中包括角色准入、工具权限与路径边界、租约丢失、取消资源终态、工具输出和兼容性；现有证据不足以支持完整 API Worker 行为验收。测试替身也没有证明真实 Agents SDK、Control Plane 或平台隐私行为。

下一轮仍严格限定于 `workers/process-typescript-with-api`。独立 Tester 应优先补齐 API-16、17、18、19、23、24、27、29、33 等可离线观察的场景，并保留其余未覆盖项；如果某项需要真实外部副作用或无法构造安全夹具，应明确保持未覆盖，不能缩小适用分母。Worker 先据本决策检查 API 入口和公开契约是否需要最小修正；若无需源码修改，应如实写明，再交给新的独立 Tester 轮次。每条新执行命令仍须单独审查和授权。

此退回不是对 15 个通过用例的否定，也不豁免 FD 的其他实现要求。原 r5/r8/r11 测试、r13 静态审查和本轮 r19 原始证据均保留历史事实。Reviewer 尚未收到正式交接。
