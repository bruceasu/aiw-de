## 发现

- **P2 确认收尾的 PowerShell 超时会清除重复计数。** `workers/process-python/progress_monitor.py:83` 仅将整数非零退出码识别为命令失败。`workers/process-python/task_shell.py:60` 至 `:80` 在命令超时后确认进程和输出管道收尾，随后返回 `status=timedOut` 和 `exitCode=null`，`workers/process-python/execution_guard.py:277` 已将该返回记为失败。重复执行同一命令并得到同一超时输出时会走 `progress_monitor.py:94` 的可能修改分支并清除计数，无法满足相同失败先提醒再停止的验收项。建议将宿主返回的 `run_shell` 超时状态纳入失败指纹，在长输出预览中保留该状态，并继续视为可能产生修改。进程未确认收尾时沿用 `PROCESS_TREE_UNCERTAIN` 路径。
