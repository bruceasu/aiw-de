## Finding

### P2：新增元数据块导致 Native app-server 的阻塞问答无法解析

Worker 将经验块从交付摘要剥离后，完成报告使用干净的 `report.summary`；但首轮复核的代码仍把原始 `final_response` 传给 `native.validate_report` 和 `native.maybe_question`。Native 的 `_json_report` 只解析纯 JSON／围栏 JSON／原有 verdict 行。现在模型输出的阻塞 JSON 后面带有 `<AIW_WORKER_EXPERIENCE>` 块时，JSON 解析失败；`input_question` 因此返回 `None`，不会建立等待用户回答的问答交接。

**最小修复：** 将 Native 验证与问答解析改为使用已去除元数据的 `report.summary`，或在 Native 解析器中明确剥离经验块后再解析。这样阻塞问题仍能进入原有等待用户回答流程。

位置：`workers/process-python/process_worker.py`（完成报告提取后仍向 Native helper 传递原始最终文本）；`workers/process-python/native_run.py`（`_json_report` / `input_question` 对尾随元数据不兼容）。
