## 发现与修复

### R1 — P2：辅助进程的同步管道写入绕过超时（已解决）

初始 `WindowsProtector.invoke` 在请求线程同步写入并关闭 stdin，之后才调用 `waitFor(15秒)`。解保护输入允许最多 16 KiB 密文，Base64 后可能超过 Windows 管道缓冲。若辅助进程在读取前停住，写入可一直阻塞，进程等待期限尚未生效；外层凭据事务与文件锁也无法及时释放。try-with-resources 的 executor.close 又会等待 stdout 读取任务，无法保证有界退出。这违反本 FD 受限辅助进程及文档所述时间上限。

修复在 [LocalModelKeyStore.exchange](../../../../src/main/java/me/asu/aidev/modelauth/LocalModelKeyStore.java:72) 将 stdin 写入/关闭和 stdout 读取放入虚拟线程 Future，共用一个单调截止时间；进程等待也使用剩余预算。异常时保持固定错误码、失败关闭，终止等待最多 1 秒，取消 I/O、shutdownNow，流关闭移到后台且请求线程最多等待 100 ms，不再无界 executor.close。敏感写入缓冲会清零。

新增两个 mock Process 用例分别阻塞输入、输出，断言有界失败返回以及需要时终止进程。Reviewer 已阅读其实际断言；这两项在首次获授权测试中通过，没有调用 PowerShell 或 DPAPI。进程创建后的期限与终止尝试不等于已经实测 Windows 系统进程的全部失败行为。

## 验收与调用链复查

1. **自动保护与复用**：新安装在 Windows CurrentUser 范围生成随机 AES 密钥，按数据库安装代次保存 DPAPI 文件；不同进程通过文件锁协调，受保护文件变化后重新解保护并核对数据库指纹。缺失/损坏或已有未知密文时失败关闭，缓存不绕过文件存在性和指纹检查。实际 DPAPI、Windows 文件原子移动及账户权限仍未运行验证。
2. **秘密边界**：数据库只保存代次/指纹；辅助脚本不把原始密钥拼入 argv，进程环境先清空再放入必要的系统目录变量，Profile 和交互关闭，错误输出丢弃，stdout 有大小上限。临时文件与目标文件保存保护结果，API 仅返回模式、状态及公开代次；没有读真实密钥或系统凭据。
3. **数据库代次与升级**：V32 新增元数据，未修改 V30/V31。显式配置优先，非法非空配置拒绝使用；首次登记显式密钥指纹前验证旧连接密文，错误密钥不会污染旧库指纹。保存/解密中的数据库写 fence 保持代次，文件操作内不再访问数据库，已检查跨进程 DB/文件锁顺序。
4. **重置与来源冻结**：[resetLocalStorage](../../../../src/main/java/me/asu/aidev/modelauth/ModelConnections.java:42) 要求非委托的当前配置管理员、显式确认与期望代次。先在同一事务切换代次，再检查其他 Owner 密文；拒绝时整笔回滚。只清本 Owner 连接和对应 proof，保留旧 Plan/Task/Worker 连接引用，不因此接入新账户；不删除工作文件。远端撤销始终明确为未确认，旧保护文件删除结果单独报告。
5. **旧请求失效**：登录和导入在外部校验前捕获 vault revision，保存事务必须再次核对；重置后本机 pending 登录取消，其他实例旧回调也不能通过代次检查。旧刷新对已删除连接的 CAS 不能重新创建记录。测试覆盖旧授权/重复重置拒绝与旧任务绑定保留；未把顺序构造的多 Vault 实例用例宣称为真实多进程联调。
6. **界面与部署**：工厂页面区分自动存储、显式高级覆盖、不可用原因和明确清除确认；重置按钮受服务端 canResetVault 与代次约束，API 复用已有控制台会话/CSRF 路由。文档明确 Windows 范围，其他平台仍需显式密钥，未知远端撤销及旧 Plan 不自动更换账户。浏览器交互只有静态证据。
