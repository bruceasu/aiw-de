# FD-071: Qt 标题栏不透明度调整为 85%

**Status:** Complete
**Revision:** 4
**Priority:** Medium
**Evidence policy:** Markdown
**Review policy:** Self

## Problem

Qt 桌面窗口的半透明标题栏仍显得过透，标题和控制按钮不够突出。用户建议将标题栏不透明度提高到 85%。

## Options and decision

- 保留当前 200/255 alpha（约 78%）：不能满足更清晰的标题栏需求。
- 提高到 217/255 alpha（约 85.1%）：采用此值；它与 85% 目标最接近的整数 alpha。

## Solution

将标题栏主题渐变的两处 alpha 从 200 调整为 217，并同步更新外观说明。工作区背景、其他组件和不透明回退不变。

## Scope

仅调整 `personal-secretary/pet/desktop_webview.py` 中标题栏 alpha 和 `docs/APPEARANCE.md` 中的对应说明。无需修改稳定能力规格。
