## Problem

FUNCTION-INVENTORY: 03. 剩余范围尚未按已确认的简化方向完成。原有代码存在不等于本轮优化已完成。

## Options and decision

优先修改现有代码，以函数和直接数据结构完成当前需要；不引入新框架、单实现抽象、重复状态库或无用兼容层。

## Solution

首版一次调整一个尚未派发的现有节点：工作流先暂停后续步骤，用户指定节点和修改要求，普通只读 Worker 生成建议，界面展示前后差异，用户确认后才应用。已派发或已提问的节点、节点类型／ID、成员、Skills、资料、目标和权限保持不变。不增加节点、不新建自动重规划框架。

Dependencies: FD-107. 复用 WorkflowRuns 的执行副本、版本检查、事件、普通简单任务和资料分页。建议生成本身是一项可观察、可停止的通用任务，费用归其执行记录。原执行停止、继续或放弃建议时终止尚未结束的生成任务；建议不能脱离原执行版本应用。无需新表、Service 或调度器。

控制边界：生成仍在运行时，继续操作先请求其停止，原流程仍暂停，待回执后再继续。原流程停止时保留子任务关联，收到实际结束证据后才显示停止成功。沿用原“任务终态且无租约”的结束判定，避免将停止请求当成成功。查看状态会收拢已经确认停止的建议；不增加后台调度器。

## Scope

仅上述保守调整范围；跨类型、增删节点、改写历史、改变权限与自动批准不实施。原定义保持不变，只修改当前执行中尚未派发节点的允许字段。正式提问与已派发工作视为已开始，不能改写。
