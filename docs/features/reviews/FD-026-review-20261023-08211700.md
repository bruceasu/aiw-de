## 确认发现

### R026-01 / P1：显式失败分流没有决定普通成功出口

位置：`src/main/java/me/asu/aidev/workflow/graph/GraphRunner.java:97`，关联第 87～90、190～198 行。

`FAILED_RECORDED` 只把 failureNext 边固定为 TAKEN，普通 SUCCESS 边仍是 PENDING。合法图 `A.success→B`、`A.failureNext→R`、`B/R→共同 END FAILURE` 中，A 失败后 R 能执行，但 B 永久等待 A 的成功边，汇合又永久等待 B 的边，连显式失败出口也无法激活。全部潜在来源必须先决定的算法使此问题可由源码直接推导；未运行该用例。

最小修正：在消费显式 failureNext 的同一事务决定互斥的普通成功出口为 SKIPPED，并传播真正未选择的后继；A 自身保持 FAILED_BLOCKED，必要失败绝不变 NOT_SELECTED。未消费、可技术重试的失败须保留其恢复语义；替代不得改写已经消费的边决定。对应 AC03、工作项 2.3/2.4。

### R026-02 / P1：祖先回跳错误等待尚未选中的父汇合任务

位置：`src/main/java/me/asu/aidev/workflow/graph/GraphRunner.java:211`，关联第 65、87～90、219～222 行；合法图检查见 `GraphValidator.java:44`。

回跳额外扫描整个 loop 当前轮的所有 TASK/ASK，仅排除 NOT_SELECTED 和已终结状态，未区分 WAITING_SELECTION 与真实选中、启动。可通过校验的图：循环 header TASK→IF；成功子范围返回父 join TASK，修复子范围 GOTO 祖先 header；该父 join 在当前分支尚未返回时必然 WAITING_SELECTION。GOTO 因此一直停在 BACKJUMP_WAITING_SELECTED_WORK，无法消费第一次回跳，稳定父出口及最多四轮的承诺无法落实。

最小修正：静止门禁检查实际已启动的 Task/Lease/效果及已打开的 ASK，不要求尚未选择的父后继先执行；在回跳事务以非成功状态关闭这些旧轮待定节点，保留稳定 activation、历史、carry 及外围分支。不得绕过仍在途或 UNKNOWN 的任务。对应 AC02/AC08、工作项 3.1。

### R026-03 / P1：整图终态漏掉同计划的规划任务

位置：`src/main/java/me/asu/aidev/workflow/graph/GraphRunner.java:44`、第 244 行；来源为 `GraphRecommendations.java:21`、第 29～37 行，控制见 `FormalQuestions.java:216`。

推荐允许在 DRAFT/ACTIVE 为同一 planId 通过 Factory 创建规划 Task，但它不在图 activation 节点中。整图取消虽对全部 execution_context 发停止请求，终态判定却只遍历 activation 的 taskId。DRAFT 的规划任务正在 RUNNING 时取消，空 activation 集合直接被判定静止，图立即 CANCELLED，规划 Attempt 的实际停止/Lease/UNKNOWN 尚未确认。ACTIVE 的并行规划任务同样可能被正常根出口遗漏。

最小修正：整图取消及根正常终态使用该计划全部受控物理任务的真实静止聚合，包含规划及 continuation、实际 Lease/Attempt 和未决效果；保留局部 loop 的范围限制。停止请求不能代替停止确认。对应共用控制、工作项 3.3/4.2。

### R026-04 / P2：公开 ASK 可选字段与实际问题入口不一致

位置：`src/main/java/me/asu/aidev/workflow/graph/GraphContract.java:41`，关联 `GraphRunner.java:106`、`questions/FormalQuestions.java:86`、`execution/guard/GuardContract.java` 的 `text`。
