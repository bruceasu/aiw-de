# 可配置给现有 AI Worker 的附加技能

FD-040 将下列九项从已吸收的角色方法补成可单独勾选的完整 Skill。它们与 `prototype` 一样，组合给现有 AI Worker，不新增 Worker 类型、进程或主角色。用户写的 `diagnosing-bus` 按现有正确名称 `diagnosing-bugs` 接入，不建立错误拼写的别名。

| Skill | 适用问题与主要产出 | 权限与宿主差异 |
| --- | --- | --- |
| codebase-design | 具体模块职责、接口和测试边界；比较可用方案，给调用/错误示例及建议 | 设计方法不自动实施或另派设计代理 |
| improve-codebase-architecture | 结构摩擦、规则泄漏、跨模块改动；比较保持现状、局部改善及必要时的较大方案 | 聚焦指定范围，不默认全库扫描、重构或创建新计划 |
| domain-modeling | 术语、概念边界、所有权、状态和不变量；给正常/反例、提案及决策影响 | 观察到的代码不等于已确认业务规则；词汇/ADR写入需原文件范围 |
| diagnosing-bugs | 已报告故障或不明失败；形成症状、证据链、原因分类、假设及候选修正 | 静态诊断优先；实验、修复、测试及重试仍依原授权 |
| resolving-merge-conflicts | 真实在途冲突；按共同基线和双方意图修复允许的部分并交接剩余状态 | 不盲选整边、reset/abort或绕过Git适配器；不明时保留现场 |
| research | 有明确问题的资料/代码研究；有来源的结论、矛盾、适用范围与证据缺口 | 可用提供材料/获准仓库读取；不自动派研究代理、联网或发外部消息 |
| handoff | 中断、换人或继续任务；保留真实结果、原身份/修订、未知操作和下一步 | 简报不是新授权或派发事件；不猜Session或重复执行未确认操作 |
| teach | 在任务范围内讲解概念或做法；短学习单元、例子、练习/反馈及下一步 | 不自动创建课程目录、学习者画像或持久会话；未观察反馈不声称掌握 |
| edit-article | 修改给定文章/文档；调整信息顺序、结构、表述并交付修订与变化摘要 | 保留作者目的、事实/引用；不默认逐节审批、发布或扩写未经证实事实 |

## 如何配置

1. 在 `/ui/configurations` 的“自定义工作方法”选择仓库和适合当前任务的基础方法。
2. 从附加 Skill 列表选需要的技能，补充任务问题、范围和完成标准；预览并保存，再用于准备任务。可以按需与 `prototype` 组合。
3. 原有上限仍是最多六个附加 Skill。按任务选相关子集，不默认加载九项；基础方法自带的技能仍由原方法提供。
4. 主方法决定职责、是否可写以及 REPORT/VERDICT/WORKSPACE。附加技能补充工作方式，不能覆盖主职责或输出合同。若主方法无法承载请求，需按正常流程调整任务/基础方法，而不是靠附加技能换角色。
5. 读文件、写文档、Git、命令、预览或外部来源仍使用真实可用且获准的工具。选中研究或诊断不代表获得网络/测试工具；当前受控工具目录没有通用网页研究工具时，应使用提供材料或报告来源缺口。

例如：在架构任务中组合 `codebase-design`、`domain-modeling` 与 `research`，围绕正式需求和许可代码给设计建议；在获准修复任务中组合 `diagnosing-bugs`，按需要再添加冲突技能；文档任务可组合 `teach`、`edit-article`、`handoff`，产出仍按原主方法和文件范围交付。

## 方法与边界

九个入口均包含实际步骤、所需输入、完成结果和缺口处理，正文为 Easy English，不引用宿主 `.agents/skills` 路径。来源是同名宿主技能及已吸收方法；适配时去除宿主自动代理、外部消息、FD命令、分支/交付、环境初始化和隐式持久状态。读取来源不等于执行九个宿主工作流。

诊断中的失败状态与原因分开，运行/修复预算按原任务保留。冲突修复只适用于真实在途操作：缺共同基线、双方意图或完成操作的受控适配器时，保留现场、说明缺口，不能绕开权限。研究引用实际读过的来源；教学练习和研究建议不是已执行结果。交接以正式输入和原操作结论为准，旧摘要不能覆盖它们。文章编辑返回修订正文或明确建议，文件保存、事实变更和发布仍按任务范围决定。

## 注册与验证

平台规范源为 `src/main/resources/worker-skills/<skill>/SKILL.md`，各包进入 `index.files` 和公共资产目录；不改 `index.profiles` 或十一份主方法。九个新 `*-v1` 资产与既有十个资产独立，原 `prototype-v1` 保留。三语言对应副本同步，但不因此宣称新的动态配置后端支持。

原附加 Skill → 配置引用 → SkillFiles 完整文件冻结 → Worker 读取链保持。旧任务/配置不自动替换；新资产随正常平台更新供新配置选择。静态和离线编译不证明真实界面、装配实例、模型使用、诊断/冲突/研究/教学或编辑效果已经运行通过。
