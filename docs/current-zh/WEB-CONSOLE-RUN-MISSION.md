# Run Mission 详情

从 **Runs** 打开 Run ID，路径为 `/ui/runs/{runId}`。Mission 是现有 Run 的展示名称。页面汇集保存的原始需求、生命周期、控制状态、有效状态、阶段和任务计数。已完成/当前任务数不表示 ETA。

## 任务与依赖

SVG 从前置任务指向依赖任务，仅使用保存的依赖边，不按任务类型推断流程。点击节点可在任务表阅读完整指令。**Hide graph** 关闭图后仍能阅读表格；密集图在内部滚动。循环会显示异常，并保留真实依赖表。

页面读取最近 200 个任务、属于这些展示任务的最多 1200 条依赖，以及该 Run 最近 300 个 attempt；各窗口明确返回数和总数。依赖还显示展示任务的候选边数。部分图、依赖截断和窗口外前置任务会明确标注。跨 Run/subject 的前置关联保留真实 ID 和范围说明，不补造缺失关系。

Attempt 保留实际 task、attempt 编号、历史 Worker、状态、时间、失败类别、终止原因和报告摘要。Worker 链接打开 Fleet；历史 Worker 不代表当前仍持有租约。窗口外 task 保留 ID，不链接不存在的任务锚点。报告摘要不代替失败根因。

## 失败与恢复

最新 Run FAILED 事件独立于时间线读取，展示实际时间、关联 task、actor 和 detail。最近 20 条 FAILED/RECOVERED 事件同时显示总数和截断。Run 事件没有保存 attempt/Worker 关联，页面不会补造；attempt 失败记录在执行历史阅读。

自动租约恢复会把过期任务重新排队；显式 Run 失败后的人工 recover 会记录 RECOVERED 事件。操作员暂停/取消同样会产生 EXPIRED；终止原因缺失时明确“未记录”，不能只凭状态判定自动恢复。后续 attempt 的创建时间不当作恢复时间。Pause 撤销活动租约；降低调度上限让现有租约自然排空；Cancel 不可逆。

## 最近时间线

时间线保留**最近最多 300 条**，随后按真实时间正序和 UTC 日期分组。显示总数、返回数、明确截断提示和实际首尾时间。类别与文本筛选只搜索返回窗口；Reset 恢复显示全部返回条目。无 JavaScript 时仍可阅读整个返回窗口。本期不提供完整历史分页或保留策略管理。

只对页面窗口内的 task/attempt 建立锚点；缺失字段明确未记录。Publication ref 仅显示文本，不读取外部文件。现有时间线服务先读取该 Run 全部投影再截断；300 条是输出上限，不是数据库读取上限或性能保证。

## 刷新与操作

只读事实每 5 秒局部刷新。共享刷新保护保留焦点/选区涉及区域、展开详情及页面滚动；编辑表单或后台页面会暂停刷新。时间线筛选、图开关和图内部滚动保持。受保护区域可能较旧，刷新标签会说明。阅读完成后可用 **Refresh facts** 或重新载入。

操作表单保留在刷新区域外，避免丢失输入。动作入口来自页面加载时快照；使用 **Reload action availability** 更新可用操作。提交继续由原服务验证权限、CSRF 和最新状态，并显示成功/错误反馈。Viewer、Operator、Approver、Admin 的权限沿用既有契约。

范围和验证证据见 [FD-002](../features/FD-002_RUN_MISSION_DETAIL_AND_TIMELINE.md)。运行测试和浏览器检查需单独记录授权。
