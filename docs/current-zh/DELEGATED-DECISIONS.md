# 有限授权代理 Worker

FD-022 为秘书工作流增加独立的 `decision-delegate` Worker。默认关闭，模型只分析冻结候选并返回建议；业务动作由服务器检查授权后执行。自然语言讨论只生成可编辑草稿，不授予权限。

## 启用与兼容

1. 配置 Web Console 人工认证。使用独立 Worker ID，选择 `decision-delegate` profile。
2. 在授权中心 `/ui/delegation` 登记已注册且无活动租约的 Worker，生成并私下保存专用随机凭证。在 Worker 环境设置 `AIW_DELEGATE_KEY`，不要写进提示词、版本库或业务报告。原共享 bearer 仍独立校验。
3. Worker 重新注册会关闭代理。确认在线状态及当前身份版本后，由管理员明确启用。
4. 第一次启用会持久收紧旧 `/api/r1/**` 管理写入：要求人工 session、CSRF 和动作角色，忽略客户端伪造的操作者字段。审批需 Approver，删除需 Admin，其余管理写入需 Operator。Drain/Offline 是管理动作；Worker 注册、心跳、领取、执行上报和输出协议保留机器认证。

首次启用须等待旧管理请求结束。进程异常退出留下的在途记录可在授权中心由管理员确认原进程已停止并填写依据后清理；不得清理仍在执行的其他实例请求。启用后关闭代理或重启不会撤销认证要求；若重启时关闭人工认证，管理 API 与控制台写入均拒绝执行。服务器重启后须重新人工启用代理。

这是已有 API 客户端的兼容变更。上线前须调整其登录、CSRF 与角色配置。本次没有运行服务、执行数据库迁移或验证实际客户端兼容。

## 授权与人工接管

在授权中心保留原文、填写具体 Worker、固定动作、目标、步骤、条件、累计上限及到期时间，检查结构化预览，再明确确认当前版本。模糊或缺少字段的规则保持草稿。允许与禁止分别记录，禁止优先；替换须指定被替换的版本。续期、换 Worker 或换模板不会重置历史额度。

A01 为完整续修轮次；A02 为精确角色及批准模型目录约束；A03 为已失败任务的一次技术重试；A04 为仅重评。A05–A10 对应计划确认、跳步、停止、收回、完成人工步骤与取消。A11 审批/拒绝分别授权，并检查独立参与及 Gate。A12 创建发布计划与执行发布分别授权；后续确认、续修或重试也不能绕过执行发布授权。A13 调整全局并行度，0 必须显式允许。A14/A15 为普通 Worker Drain/Offline。A16 为结束计划归档；A17 延迟删除/撤销分别授权且须管理员当前权限。

发布执行许可固定到具体任务的单次 attempt，绑定授权版本和本次代理身份。租约过期重领、评审自动生成返工任务都不能复用许可；授权撤销、到期、替换或代理关闭后，未启动的代理发布许可不再可用。没有许可的任务留待人工处理或明确交回后重新走 A12_EXECUTE，逐次计入同一物理发布目标的累计账本。已 CONFIRMED 的发布 Plan 可用 A12_EXECUTE 为唯一等待执行的任务重新取得单次许可；FAILED 任务仍先走原重试流程。人工从原确认/续修/重试入口操作保留其显式许可；机器自动返工不获得人工许可。

执行和评审的 Worker 隔离依据 Plan 加步骤的全部历史尝试，覆盖重试、恢复评审及同 ID 更换 profile。代理审批还检查 Gate 源执行者与评审/验证者的历史交集。不同 Worker 可以使用相同模型。禁止规则与允许规则共用状态及轮次条件；当前适用的禁止规则转为带原因的人工待办。

动作表单列出对应参数。模型配置须使用当前目录版本及允许 profile；重试须明确失败类型与副作用确认；发布须固定输出文件、哈希、PASS 评审和规范路径。路径别名不自动接受。

撤权、过期、关闭、重注册、目标变化或人工操作会令旧候选失效。人工待办保留原因，不能超时自动通过。人工处理后须明确“交回”，系统再生成新候选；上线或恢复心跳不会自动交回。

## 额度、历史与模板

步骤使用 Plan 加步骤的累计键，非步骤使用稳定对象加具体动作的累计键。完整轮次、技术重试和仅重评分账；执行和独立评审完成（PASS 或 REPAIR_REQUIRED）均计一完整轮。启动失败不隐式返还已开始的轮次；未启动且明确取消才按补偿记录释放预留。追加额度填增加量，不填新的余额。

目标纳入前检查旧 V4 待执行授权与未结算修复，导入已有消耗基线。V4 不会自动扩权，V5 回答也不是权限。授权中心提供当前可用状态、规则及模板版本来源、人工待办、消费与审计记录。

模板只保存规则与来源版本。复制后重新绑定目标、Worker、到期时间并人工确认；不复制凭证、启用状态、消耗或决策历史。编辑或删除模板不改变已有授权。
