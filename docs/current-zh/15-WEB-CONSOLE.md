# Web Console

当前产品只提供灵活计划。访问 `http://127.0.0.1:8080/ui` 会进入计划列表。

## 页面

| 路径 | 用途 |
|---|---|
| `/ui/plans` | 当前计划 |
| `/ui/plans?view=archived` | 已归档计划 |
| `/ui/plans/new` | 编辑并保存计划草稿 |
| `/ui/plans/{id}` | 计划、真实任务、评审与管理决定 |
| `/ui/workers` | Worker、待领取任务和活动租约 |
| `/ui/system` | Fleet 调度与诊断 |

草稿保存不会创建 Worker 任务；操作员确认当前版本后才创建第一步。详情可查看步骤产出、独立评审、跳转和提前结束记录。运行中的任务须收到 Worker 停止确认后，跳转或结束才生效。

## 归档和删除

已停止、已收回，或最终步骤通过独立评审且没有未结束任务的计划可以归档。归档只从默认列表隐藏，详情仍可查看。管理员可标记删除；30 天内可撤销。到期后后台每小时尝试以单个事务删除计划及其 Control Plane 数据库关联记录。若任务状态或引用阻止清理，事务回滚并在下次调度重试。工作目录与 Git 成果不清理。`aidev.web-console.plan-purge.interval-ms` 可调整检查间隔。

## 旧固定 Run

固定自主 Run 的创建与管理 HTTP 入口已移除；旧 `/ui/runs` 路径只重定向到计划列表。开发测试库应按单文件 V1 基线以空数据库重新初始化。旧 Run 表在新基线结束时删除，旧数据不会被自动转换成计划。部分旧 Java 投影类尚留在源码中，但不再进入当前页面或创建路径。

### 侧栏显示

侧栏左侧显示 `AIW`，悬停提示为 `AI Worker`；右侧显示 `Digital Employee`，不显示重复的品牌标题或版本副标题。
底部可选显示浏览器本地时间、日期及时区；显示时间时每秒更新，仅显示日期时每分钟更新。页面隐藏或日期时间均关闭时暂停更新。
侧栏底部的“个性化偏好”统一管理语言、外观、日期时间和动画；首次使用默认 English，已有语言偏好继续保留。

### Plan 右侧工具栏与浮动窗口

Plan 页面右侧固定工具栏随视口保持可见，滚动页面后仍可直接使用。
图标分别打开“决策历史”、Mission Control、修复授权历史，以及适用时的归档窗口。
Mission Control 入口仅向有操作权限的用户显示。窗口默认隐藏，不再占用主页面的纵向空间。

点击图标打开或隐藏窗口；拖动标题栏移动窗口，标题栏聚焦后也可用方向键移动（Shift 加大步长）。
窗口右上角可以最大化、还原或隐藏；Escape 隐藏当前聚焦窗口。隐藏不清空已填写的内容，重新打开仍保留。
多个窗口可同时打开，点击窗口将其置于前方；窗口内容在内部滚动，窗口尺寸及拖动位置受视口约束。

`NEEDS_ATTENTION` 会同时显示顶部警示条、醒目的计划状态，以及 Mission Control 工具图标上的黄色提醒标记。
提醒根据实际派生的计划状态显示；进入授权决策等待、继续执行或人工结束后会随状态更新消失。

### 待决问题与来源文件

右侧问号工具直接打开“待决问题与文件”，数字角标表示尚无已确认回答的问题数量。
页面从每个步骤当前已完成的执行交付物中提取 JSON 的 `payload.openQuestions`（或根对象 `openQuestions`），
展示编号、问题、上下文、关联项及来源任务、文件 SHA-256。来源可能尚未通过独立评审，其状态会一并展示；提取不等于批准。
非结构化报告和超过 1 MiB 的 JSON 仍可在相关文件中查看，提取限制会提示，不自动猜测问题或答案。

每个问题可以直接预览、下载来源或打开来源任务；“相关文件”也包含当前步骤的执行和评审报告。
预览只显示文本，最多 65536 个字符，完整内容仍由原交付物下载接口提供。
操作员填写结论后明确确认；记录绑定问题、文件版本、确认人、时间和计划版本。回答可以修订，旧记录保留在回答历史。
文件版本变更不会自动沿用旧回答。表单草稿在当前页面保留，未提交的草稿不会成为任务输入。

待处理/运行中的任务、未完成的计划控制或有效待处理授权存在时，只能查看和拟答，不能确认修改。
确认答案只补齐问题决策，不启动工作，不改写已完成的报告、评审结论或正在运行的指令。
后续新执行、独立评审及授权决策任务会携带已确认结论；失败任务重试时通过可审计指令修订更新输入。
需要继续编码时，在 Mission Control 另行授权一轮修复。不能把“已回答”视作“已实现并通过评审”。

部署需应用新增 `V5__workflow_question_decision.sql`，只增加决策表和索引，原交付物不变。
数据库迁移未在本次开发中执行；上线前备份并由正常 Flyway 启动流程应用。回退应用时保留新增表及审计数据，
不要通过删表回滚回答。计划按既定保留策略永久删除时，同时清理其回答记录。

接口：`GET /ui/plan-editor/plans/{id}/questions`、`GET .../questions/files/{fileId}`、
`POST .../questions/answers`。写请求使用现有操作员权限与 CSRF，包含计划版本、问题 key、来源文件 ID/哈希、回答及显式确认。
接口验证最新来源和版本，不接受客户端指定确认人。决策正文每条最多 2000 字符，总任务决策上下文最多 8000 字符；超限明确拒绝，不静默丢弃决策。

### 浮动窗口外观

所有浮动窗口统一从“个性化偏好”调整背景不透明度，默认黄金分割点 61.8%，可调范围 55%–100%，精度 0.1%；数值越低越透明。
不再提供各窗口独立滑块，旧的逐窗口透明度不沿用。偏好保存在当前浏览器，关闭再打开或刷新页面后继续使用；存储不可用时仍可在当前页面调节。
仅背景半透明，文字和控件保持不透明；青蓝渐变标题栏、柔光边框和背景模糊沿用控制台配色。
键盘方向键可调整偏好面板中的滑块。高对比度模式采用系统实色和边框以保持可读性。

### 个性化偏好

统一面板包含窗口背景不透明度、显示语言（English/简体中文）、侧栏时间开关、日期与时区开关、动画开关。
修改立即应用并自动保存到 `aiw-preferences`；支持同一浏览器标签页同步。“恢复默认设置”恢复 61.8%、English、显示日期时间及启用动画。
语言和动画会迁移旧的 `aiw-locale`、`aiw-motion` 选择；顶部独立动画按钮与侧栏独立语言选择器移除。
系统的“减少动态效果”优先于启用动画，面板会显示说明；用户的动画偏好仍保留。设置仅影响界面，不修改 Worker、Plan 或执行授权。
