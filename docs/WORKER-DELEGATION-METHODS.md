# 委派判断、证据交接与执行记录

FD-043 将文章中适合现有平台的部分落为可配置技能、规划与交接方法，以及当前账号的只读执行记录。角色内仍由同一个 Worker 使用多个技能；需要跨 Worker 时，仍交给平台图编排。

## 怎样使用

在 `/ui/configurations?view=roles` 组合角色时，为需要判断工作边界的步骤选择“委派判断”（`delegation-planning`）。也可以在原“自定义工作方法”的附加技能中选择它。它与 `research`、`codebase-design`、`handoff` 等技能组合使用，既有技能数量上限不变，无须增加 Worker 类型或进程。

例如，“方案研究与设计”角色可以先判断问题是否需要独立资料研究，再研究、比较接口并交接。技能在原任务结果中给建议：选择什么方式、理由是什么、输入和完成条件有哪些、由谁消费结果、怎样合并结论。它不直接启动代理、创建任务或切换模型。真实派发仍需现有平台任务和授权。

| 工作情况 | 适合的方法 |
| --- | --- |
| 连续调试、证据高度共享、后一步依赖前一步决定 | 留在当前 Worker，保留完整状态 |
| 有独立问题、明确输入与来源范围，可交付有引用的结论 | 建议隔离研究，交接关键决定及原证据位置 |
| 需要独立判断自己产出的风险 | 建议独立审阅，不用输入 token 数量限制审阅价值 |
| 问题能分开、共享接口已固定，结果有明确合并责任人 | 提出有边界的并行方案，列出依赖、失败和合并条件 |

模型建议只能使用任务提供的已批准配置或表达所需能力，不修改当前固定模型。缺权限、来源或执行能力时报告缺口。技能选择不授予网络、命令、写入、Git、额外重试或新的预算。

## 交接保留什么

规划、共享工程协议及 `handoff` 增加了证据索引方法：把主要结论连到原来源、精确版本和位置，记录实际观察、限制、反证、已作决定及下一位消费者。原始数据与产物留在原位置，摘要只提供入口。关键决定可以有理由地重新读取；摘要不能覆盖正式输入、未知操作或已消耗的执行授权。

这些方法使用现有描述字段，不引入新的结果顶层格式或角色内步骤状态。Worker 自报完成、自己复查或交接摘要均不等于独立验收。

## 查看实际记录

需要在运行中补充工作或比较探索方案时，可从执行记录进入 [Worker 工作台](WORKER-WORKBENCH.md)；原观察页继续只读，新输入仅在明确支持的尝试上开启。

打开 `/ui/configurations?view=observations`，也可以从组合角色页或自定义工作方法区进入“执行记录”。页面只读当前登录账号对应 Owner 的最多最近 100 个已建账本的尝试，按尝试创建时间排序，手动刷新。

每行关联任务、尝试、固定工作方法、实际选择的模型配置与后端，以及累计输入/缓存/输出 token、已存耗时和费用、执行状态和 Worker 上报结论。展开可查看固定配置、结果版本、正式交付摘要和来源引用，以及未运行检查、未决项数量。交付来源最多列出 16 项并显示总数；不自动打开外部地址。

| 字段或缺口 | 含义 |
| --- | --- |
| 输入与缓存 | 缓存是输入的子集，不再次相加；未知用量或未开始计量不显示为已知零 |
| 耗时与费用 | 显示已有值，不推算运行中的最终值；费用为微单位并保留原计价单位，缺值显示未知 |
| UNKNOWN 标记 | 与已有值并列；人工校正可能补充值而保留原未知标记 |
| 上报结论 | Worker 的原结论，不是独立质量分数或验收结果 |
| 同结果再次读取 | 同一尝试中，成功 READ 且资源和结果摘要相同的额外次数；不是所有读取或浪费判定 |
| 无记录 | 不代表未执行；页面不是全局汇总 |
| 启动开销、协调比例、真实质量分数 | 尚未采集，不填估计值或从 verdict 推算 |

接口是已有受保护路径上的 `POST /api/r1/authority/execution-configurations/state?kind=observations`，请求 `{}`，响应 `aiw.execution.observations.v1`。沿用真实浏览器会话、CSRF、操作角色及服务器 Owner 校验。它不返回凭证、lease token、机器会话、完整任务说明、命令参数或完整结果正文，不写入账本或改变预算策略。

## 兼容与验证边界

只追加一个公共技能资产。原十九个资产、十一份默认方法与启动 profiles 保持；方法资源更新会产生新文件包 manifest。新任务冻结当时的文件，旧配置及已有任务、重试和续行保留原冻结字节，不被追写。三语言独立技能副本同步，不因此增加动态配置后端。

不采用固定 1 万 token、0.3 开销比、“节省 60%”或品牌型号路由规则，也不增加自动派发器、预算门禁、数据库表或迁移。回退旧平台后新记录页不可用，原账本不删除；旧目录没有新技能时，暂停创建/准备引用新技能的配置，不偷偷换默认技能。

静态证据和生产源码编译只能支持结构与编译结论。模型是否按方法执行、数据库查询、实际浏览器显示及回退效果需要后续有界运行证据，本次不部署或运行真实任务。
