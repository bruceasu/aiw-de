## 使用者、问题与目标

秘书使用者希望能够完整查看并导出秘书与模型交互的记录。现有界面与 API 已展示真实活动、结果和秘书回复过程，但完整原始交互导出范围尚未定义。

目标是让使用者能够选定会话或执行记录，导出其可用的交互记录，以便查看、保存和调查执行过程。导出不应更改或重放原执行。

## 已确认输入

- 用户要求先为“完整交互日志导出”创建需求。
- 用户要求记录 Worker 与模型交互，以便观察工作状态；现有功能清单记录了会话日志与回复过程查看能力。

## 范围与非目标

候选范围是导出已记录且可供系统读取的会话和执行交互数据，并保留消息、工具活动和结果之间的顺序与关联。

本 Issue 暂不承诺导出模型服务端不可见的内部推理，也不改变当前记录采集、保留或模型执行策略。是否导出系统提示、工具参数／结果、附件内容、Token 用量、错误详情和完整模型响应，待确认。
